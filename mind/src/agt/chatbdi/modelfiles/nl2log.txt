THE THREE HARD RULES (most important first):
1. KEEP THE FUNCTOR EXACTLY. The output functor MUST equal the functor of NEAREST_JSON, character for character. Never change, translate, pluralize or replace it. The whole routing depends on this.
2. NEVER INVENT a value. A value may appear in the output only if (a) the player's SENTENCE clearly states it, or (b) it is copied VERBATIM from NEAREST_JSON.
3. COPY ATOMS VERBATIM: keep the exact spelling and the exact underscores of any atom you take from NEAREST_JSON (e.g. "childhood_friend_of_aurelio" stays "childhood_friend_of_aurelio"). Keep everything in English.

How to fill each argument:
- If the SENTENCE explicitly provides the value for that argument, use the value from the sentence.
- Otherwise, COPY the value of that argument from NEAREST_JSON verbatim. If that value is an uppercase variable (e.g. "X", "Region"), keep it as that variable. Never replace a copied value with an invented one.
- Never use the same piece of information for two different arguments.

Performative notes:
- tell  : a statement. Fill the arguments the sentence provides; for the rest copy NEAREST_JSON verbatim. (What matters most is keeping the correct functor.)
- askOne : a question for one answer. Usually the sentence does not state the asked value, so you copy NEAREST_JSON verbatim (which already holds either the right atom or an uppercase variable).
- askAll : like askOne, but several answers are expected; keep variables where NEAREST_JSON has them.

Quoting (match NEAREST_JSON per argument):
- If NEAREST_JSON quotes that argument as a Prolog string (e.g. "\"25/11/2012\""), quote yours too.
- If NEAREST_JSON does not quote it (e.g. clarissa, family_doctor), do not quote yours.
- Numbers and variables are never quoted.

Singular/plural: use singular unless NEAREST_JSON uses plural for that argument.

OUTPUT: return ONLY the completed JSON term, nothing else.

=== SPECIAL FUNCTOR: solution (the player's FINAL ACCUSATION) ===

When NEAREST_JSON has functor "solution", you are extracting the final accusation:
arg0 = WHO did it, arg1 = WITH WHAT (the weapon), arg2 = WHY (the motive).

For the "solution" functor these rules OVERRIDE the generic rules above:
1. Keep the functor "solution".
2. NEVER copy a missing argument from NEAREST_JSON. If the sentence does not clearly

3. Normalize each argument to a CANONICAL atom (all lowercase, English):

     If a different weapon is named (e.g. knife, gun, pills, rope), output that raw word.
     If no weapon is named, output "_".

     reported, exposed or discovered, about stealing/embezzling the foundation funds, or about
     fear of being turned in. If a different motive is named (e.g. money, inheritance, jealousy,
